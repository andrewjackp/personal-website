# Contentful-backed landing page

A static page that fetches a "Campaign Landing Page" entry from Contentful's
Content Delivery API and renders it — hero, body (rich text), CTA, and linked
promo modules. Content is modeled in Contentful (content types, reference
fields, localization); this is the front end that consumes it.

Built as a hands-on exercise with headless CMS / Contentful.
